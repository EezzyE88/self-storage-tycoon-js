## Begin a task safely and efficiently

1. Resolve the user's current task. Do not infer authorization for gameplay changes from a roadmap.
2. Reverify master and the specific candidate. Keep accepted work intact and use an isolated branch for new work.
3. Check only the evidence needed for that task. Historical tests are not new passes; prior scoped passes need not be repeated without cause.
4. For playthroughs, verify a company-save backup and separate disposable copy before replacing any company. A source ZIP is not a company backup.
